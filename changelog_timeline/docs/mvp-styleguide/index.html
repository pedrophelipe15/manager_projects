Spacing existe

Grade de 4px. Use sempre var(--sp-*); nada de valores soltos.

Radius & elevation existe

No tema claro a elevação vem de sombra suave + borda sutil, nunca de gradiente ou blur.

Buttons existe

Primário = 1 por área (CTA). Destrutivo sempre --danger com confirmação. .btn--md 38px, .btn--sm 32px.

Chips e badges proposto

Chip = ação do usuário (filtro)
Badge = estado de um dado (somente leitura)

Cor só para significado (ok/atenção/risco). Nunca como decoração. Estado nunca só por cor: sempre com texto.
